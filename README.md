# 🧮 JavaScript Simple Calculator

A simple calculator project developed using **HTML, CSS, and JavaScript**. This project performs basic mathematical operations and helps beginners understand JavaScript calculations.

## 🌐 Live Demo
[Click Here to View Project](https://zaidy7433.github.io/java-script-simple-calculator-/)

## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Takes user input.
- Displays calculation results.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📚 What I Learned
- JavaScript variables.
- `prompt()` function.
- `alert()` function.
- Mathematical operators.
- `if/else` statements.
- Basic calculations.
